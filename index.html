I'm a second-year Computer Science student at Thakur College of Science and Commerce, Mumbai, currently building my technical foundation — learning Python fundamentals, working comfortably in HTML and Git, and getting used to AI-assisted workflows with tools like ChatGPT, Gemini, and Claude.
